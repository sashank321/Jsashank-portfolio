## 2024-10-24 - Add Security Headers to Next.js App\n**Vulnerability:** The Next.js application was missing standard HTTP security headers (e.g., Strict-Transport-Security, X-Frame-Options), leaving it potentially vulnerable to common web attacks like clickjacking and MIME-type sniffing.\n**Learning:** Next.js allows configuring these globally via the `headers()` function in `next.config.ts`. It's a quick and highly effective defense-in-depth measure.\n**Prevention:** Always include a baseline set of security headers for Next.js applications during initial setup.
