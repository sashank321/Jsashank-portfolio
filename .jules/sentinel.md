## 2025-02-23 - [CSP Exceptions for Animation Libraries]
**Vulnerability:** Weakened Content-Security-Policy (CSP) by allowing `'unsafe-inline'` and `'unsafe-eval'`.
**Learning:** In a Next.js application heavily utilizing GSAP and Framer Motion for UI animations, these animation libraries rely on inline styles and sometimes dynamic evaluation (or inline scripts for setup). Enforcing a strict CSP without these directives breaks the core visual features of the application.
**Prevention:** Always test CSP changes thoroughly against the frontend functionality. When using GSAP/Framer Motion, `'unsafe-inline'` for styles and scripts, and `'unsafe-eval'` for scripts are unfortunately necessary unless the application architecture is changed to completely remove these dependencies or pre-calculate all animations (which is often infeasible for dynamic interactive portfolios). Ensure other headers like `X-Frame-Options` and `X-Content-Type-Options` are strictly enforced to compensate for the loosened CSP.
